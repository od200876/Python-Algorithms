# 50 Algorithms Every Programmer Should Know

Python implementations of 50 fundamental algorithms every programmer should know — data structures, sorting, searching, recursion, graphs, dynamic programming, and more.

## 🎯 Goal

This repositorie is where I practice and consolidate my understanding of classic algorithms by implementing them myself, with tests and clear explanations.

## 📂 Project structure

```
Python-Algorithms/
├── Linked List/         
├── Stack/              # Stack (LIFO)
├── Queue/              # Queue (FIFO)
├── sorting_searching/
├── Tree/
└── README.md
```

*(more folders will be added as new algorithms are implemented)*

## 🚀 Usage

Clone the repo:
```bash
git clone https://github.com/od200876/Python-Algorithms.git
cd Python-Algorithms
```

Run an algorithm:
```bash
python3 Stack/class_.py
```
